Lean Apps

Small, offline viewers for local files

Three read-only desktop apps that open a Word document, a huge CSV file, or a Markdown file without the heavy application that usually comes with it. Each is MIT licensed and free.

The apps

  • LeanDoc: Word (.docx) viewer for Windows, Linux and macOS

    Reads .docx files as pages without Microsoft Office. Macros never run and nothing the document points to is fetched.

    A 600 KiB Linux package; no office suite needed

    winget install abooodbah.LeanDoc

    Website Microsoft Store Source

  • LeanRows: large CSV viewer for Windows

    Opens CSV, TSV, JSON Lines, and log files too big for Excel, keeping only the visible rows in memory.

    20 million rows, 1.5 GB, 18.4 MB peak working set

    winget install --id 9NMV8GKJXSN0 --source msstore

    Website Microsoft Store Source

  • LeanMark: Markdown viewer with Mermaid for Windows, Linux and macOS

    Reads .md files, GitHub-flavored Markdown, and Mermaid diagrams offline, without opening an editor.

    About 74 ms to a visible window on Windows 11

    winget install abooodbah.LeanMark

    Website Microsoft Store Source

Scoop needs the bucket once:

scoop bucket add lean https://github.com/abooodbah/scoop-bucket
scoop install lean/leanrows

Homebrew:

brew install --cask abooodbah/tap/leandoc

Chocolatey needs an administrator shell. A new version reaches it once Chocolatey's moderators have approved the package: 

choco install leandoc -y

The GitHub Windows builds are unsigned, so Windows may show a SmartScreen warning; the Store builds are signed by Microsoft. The macOS builds are previews that are not notarized.

Android

Help test the Android apps

LeanDoc, LeanMark and LeanRows for Android are in a closed test on Google Play before their public release. Google needs testers who keep the apps installed for 14 days. Use the Google account you have on your phone.

Join the testers group

Then, on your phone, open each tester page, tap Become a tester, and install the app from Google Play. If a page says the app is not available yet, Google is still reviewing the test; try again a day later.

What the three have in common

Read the file, change nothing

  • Read-only. None of them edits or saves the file it opens.
  • Offline. Their own code makes no network requests. LeanDoc and LeanMark draw pages with the system web runtime, which may contact its vendor on its own; LeanRows is a plain Win32 app.
  • No telemetry. No account and no tracking.
  • MIT licensed. The source of each app is on GitHub.
